Pilares de la Programación Orientada a Objetos

PilarDescripción
AbstracciónOcultar detalles internos y mostrar solo las características relevantes.
EncapsulamientoProteger los datos de un objeto para evitar accesos indebidos, promoviendo el uso de métodos públicos para interactuar con ellos.
HerenciaPermite que una clase reutilice los atributos y métodos de otra, promoviendo la extensión y personalización.
PolimorfismoHabilidad de un método o función para comportarse de diferentes maneras según el objeto o los argumentos con los que interactúa.
